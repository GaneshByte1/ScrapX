# UI Stories Stub

This package provides primitive UI components designed to work across Web and Native via react-native-web and nativewind.

Storybook or other documentation tooling can consume these components from `@repo/ui`.

Example (pseudo):

```tsx
import { Button } from '@repo/ui';

export default { title: 'Primitives/Button' };

export const Primary = () => <Button label="Click me" />;
```
